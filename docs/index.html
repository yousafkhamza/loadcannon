loadcannon

One config format to load-test internal and public APIs — LB, direct IP, or hostname — with secrets resolved securely at run time.

curl -fsSL https://yousafkhamza.github.io/loadcannon/install.sh | bash

Why

Most load-testing setups end up as one-off k6 scripts with tokens pasted inline. loadcannon separates what you're testing (a scenario file) from how the secret gets there (env, file, AWS SSM, or a masked prompt) — and from where the target actually is (public hostname, internal LB, or a bare IP behind a Host header override).

validate

Resolves auth and fires one baseline request before you spend VU-minutes on a broken config.

run

Generates a k6 script and executes it, streaming k6's own output, then renders an HTML report.

gen-k6

Just want the script? Emit it without running, to hand off to a CI runner or another engineer.

tunnel-ssm.sh

Reach a private-subnet endpoint via SSM port forwarding — no VPN, no open ports, IAM-authenticated.
